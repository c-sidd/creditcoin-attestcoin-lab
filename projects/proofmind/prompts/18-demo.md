# Prompt 18 — Ideathon Demo Rehearsal

```text
Prepare and rehearse a 3–5 minute judge-facing demo.

The demo must show a real or clearly labeled recorded testnet run and explain:
1. problem
2. why ordinary AI/oracle architecture is insufficient
3. source-chain event
4. Attestcoin cryptographic verification
5. VerifiedFact
6. AI reasoning
7. deterministic on-chain policy
8. Creditcoin execution
9. evidence dashboard

Prepare a fallback recorded run if live infrastructure is unreliable, but clearly label recorded evidence.

Create a demo checklist and ensure every displayed hash/address is real and traceable.

Gate: PASS when the complete story can be demonstrated without hand-waving undocumented protocol behavior.
```
