# Prompt 15 — E2E Evidence Capture

```text
Create a reproducible evidence package for the successful testnet run.

Create one Markdown record under projects/proofmind/evidence/e2e/ containing:
- run ID and date
- source network/chain key
- source contract
- source transaction hash/block
- exact event fields
- attestation status/block
- Proof Builder metadata
- proof status
- ASC address and Creditcoin transaction hash
- verification result
- VerifiedFact
- AI model/provider/version and structured decision
- policy validation result
- final execution transaction/state
- links where publicly available
- screenshots only when they add useful proof
- known limitations

Never commit private keys, API secrets, seed phrases, or raw sensitive credentials.

Gate: PASS only when another developer can use the record to independently verify the run.
```
