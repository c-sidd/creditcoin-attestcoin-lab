# Prompt 12 — Evidence-First Dashboard

```text
Build the simplest useful dashboard.

Main view: one cross-chain event timeline.

Show separately:
1. source event
2. attestation
3. proof generation
4. cryptographic verification
5. VerifiedFact
6. AI reasoning/decision
7. on-chain policy validation
8. Creditcoin execution

For every transaction show network, hash, block and link when available.

Never present AI output as cryptographic proof. Never add a UI execution bypass around the policy contract.

Add loading/error/unknown states and tests for incomplete lifecycle data.

Gate: PASS when a real evidence record can be followed from source event to final execution.
```
