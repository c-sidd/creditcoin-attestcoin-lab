# Prompt 30 — Evidence Viewer

Build the detailed evidence view for one cross-chain event. Show source tx/block/event, attestation status, proof-generation status, ASC submission, verification/execution result, AI decision, intent, and resulting Creditcoin transaction using only backend evidence.

Never display fabricated hashes or mark mocked evidence as real. Provide copyable identifiers and clear network labels. Test partial progress, failure, missing fields, and completed flows.
