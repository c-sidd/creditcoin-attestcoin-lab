# Prompt 03 — Project Scaffold

Read prompts 01–02 and the development/technology-stack docs.

## Goal
Create only the implementation skeleton required for the documented architecture. Do not implement business logic yet.

## Expected areas
`contracts/`, `worker/`, `ai/`, `backend/`, `frontend/`, `scripts/`, and `tests/` as required by the actual chosen stack. Add README files where a component needs local instructions.

## Rules
Reuse the repository's established tooling where possible. Do not invent dependencies just to fill folders. Keep protocol examples untouched.

## Verify
Install/build/lint the scaffold using the project's actual package managers and ensure empty or placeholder modules do not break builds.

## Documentation
Record the final implementation tree, commands, dependency decisions, and local run instructions.

## Acceptance
Clean scaffold; reproducible setup; no secrets; no unrelated changes; every created component maps to a documented architecture component.
