# ProofMind Changelog

This is a human-readable record of important project changes.

## 2026-08-18 — V2 product direction

- Reframed ProofMind as Attestcoin-powered cross-chain AI credit and risk intelligence.
- Replaced the generic single-agent story with five logical agent roles: Financial Analyst, Risk, Fraud/Anomaly, Credit and Policy.
- Added deterministic financial risk metrics as a companion to AI reasoning.
- Added explicit scenario simulation as a deterministic, non-predictive component.
- Strengthened the VerifiedFact input boundary and on-chain policy enforcement.
- Updated solution, data contracts, decision contract, dashboard/API, demo, roadmap and ideathon pitch documents.
- Added a dedicated V2 Antigravity implementation prompt.

## 2026-08-18 — Documentation control plane

- Added an explicit implementation status board.
- Added deep engineering documentation categories for Antigravity.
- Clarified the distinction between Creditcoin protocol facts, ProofMind project design, and implementation instructions.
- Added operational guidance for AI boundaries, contracts, worker state, APIs, UI, security, testing and environments.

## Change discipline

Every meaningful architectural change should update `DECISIONS.md`, the affected specification, and the implementation status when appropriate.
