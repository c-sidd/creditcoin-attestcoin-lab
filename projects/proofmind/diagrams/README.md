# ProofMind Diagrams

Keep architecture diagrams close to the specifications and update them when interfaces change.

## Required diagrams

- `system-architecture.md` — all major components and trust boundaries.
- `cross-chain-flow.md` — source transaction through Attestcoin verification.
- `ai-flow.md` — verified fact to bounded AI proposal to policy enforcement.
- `worker-flow.md` — worker state machine and retry paths.
- `contract-flow.md` — source, ASC and decision/business contract interactions.

Diagrams are explanatory. They must not be treated as authoritative protocol ABI documentation.
