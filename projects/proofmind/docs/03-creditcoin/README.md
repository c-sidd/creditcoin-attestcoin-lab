# 03 — Creditcoin / Attestcoin Protocol Reference

This folder contains the **protocol-specific source-of-truth layer**.

## Rules

1. Creditcoin facts must come from the official documentation or the existing tutorial/reference implementation in this lab.
2. Do not invent Proof Builder endpoints, precompile ABIs, SDK methods, chain IDs, chain keys or event encodings.
3. When the docs are conceptual and code requires an exact interface, inspect the reference implementation before coding.
4. Record any unresolved protocol question rather than guessing.
