# End-to-End Tests

## Canonical scenario
1. Deploy/configure source contract.
2. Submit source action.
3. Observe dedicated event.
4. Wait for attestation.
5. Obtain proof package.
6. Submit ASC transaction.
7. Confirm proof verification and business event.
8. Persist normalized evidence.
9. Run AI decision.
10. Validate policy.
11. Execute Creditcoin action.
12. Confirm final event and dashboard evidence.

## Required evidence
Capture source tx hash, source block, proof request/reference, ASC tx hash, decision ID, intent hash and final Creditcoin tx hash.

A complete E2E run is the minimum evidence needed to call the MVP cross-chain flow demonstrated.
