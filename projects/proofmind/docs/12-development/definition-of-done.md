# Definition of Done

A milestone is done only when:

- implementation exists;
- unit tests cover core behavior;
- failure cases are tested;
- interfaces match the documentation;
- environment configuration is documented;
- logs/errors are understandable;
- security controls are present;
- README/status are updated;
- testnet evidence exists when the milestone depends on a live chain;
- no known critical TODO remains hidden in the code.

**Code existing is not evidence of completion.**
