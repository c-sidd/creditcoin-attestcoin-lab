# 00 — Project Context

This folder answers **what ProofMind is before discussing implementation**.

## Documents

- `overview.md` — canonical project definition and scope.
- `problem.md` — user/developer problem being solved.
- `goals.md` — measurable MVP goals.
- `non-goals.md` — explicit exclusions that prevent scope creep.
- `terminology.md` — shared vocabulary and ambiguous terms.

## Classification rule

Each statement should be labelled mentally as one of:

- **Protocol fact:** supported by Creditcoin documentation/reference code.
- **Project design:** a ProofMind decision.
- **Implementation note:** an instruction for the coding agent.

Antigravity must not convert a project design into a claim about Creditcoin itself.
