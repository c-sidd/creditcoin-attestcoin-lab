# Non-Goals

The MVP does **not** attempt to:
- replace Creditcoin Attestors or the Attestcoin protocol;
- implement a new oracle or consensus mechanism;
- claim that an AI model itself provides cryptographic truth;
- provide unrestricted autonomous wallet control;
- support every source chain or every Creditcoin environment;
- build a production-grade financial product;
- hide protocol delays or pretend cross-chain execution is synchronous from the user's first transaction;
- depend on undocumented precompile behavior.

Stretch features must not weaken these boundaries. If a feature requires new protocol behavior, document it separately as a dependency or future work.
