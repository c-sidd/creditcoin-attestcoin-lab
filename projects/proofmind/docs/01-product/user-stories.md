# User Stories

- As a user, I can initiate one source-chain action that emits a uniquely identifiable event.
- As a user, I can see the event's processing state.
- As a user, I can inspect source transaction and Creditcoin transaction references.
- As a dApp builder, I can configure the source contract and ASC addresses without changing business logic.
- As an operator, I can retry recoverable worker failures without duplicating a completed event.
- As an AI engineer, I can provide verified data to the model through a typed schema rather than arbitrary blockchain text.
- As a security reviewer, I can verify that AI output is checked by deterministic contract policy before execution.
