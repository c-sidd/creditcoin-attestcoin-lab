# Prompt 35 — Security Audit

Audit contracts, worker, backend, AI boundary, frontend, configuration, and deployment.

Check access control, replay/idempotency, malformed proofs/data, arbitrary calls, unsafe external calls, integer/bounds errors, secret leakage, prompt/data injection, unauthorized transaction intent, RPC trust assumptions, dependency risks, and logging of sensitive material.

Run static analysis and tests available in the stack. Classify findings by severity, fix critical/high issues, add regression tests, and document accepted residual risk. Do not claim secure merely because automated tools are clean.
