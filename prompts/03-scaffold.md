# Prompt 03 — Project Scaffold

```text
Create only the minimum implementation scaffold required by the verified architecture.

Separate source-chain contracts, Creditcoin contracts, worker, backend, AI adapter, dashboard, tests, scripts, and configuration.

Do not add speculative protocol wrappers.

Add:
- package/tool configuration
- environment template with placeholders only
- local development commands
- test commands
- lint/format commands
- deployment script skeletons
- README for implementation layout

Run every available build/test command.

Gate: PASS only if the repository can install/build/test the scaffold without secrets and all commands are documented.
```
