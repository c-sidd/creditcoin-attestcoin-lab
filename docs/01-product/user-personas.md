# User Personas

## 1. dApp builder
Needs reliable cross-chain facts, predictable integration boundaries, retries, and inspectable evidence.

## 2. End user
Wants to sign the source transaction once and understand what happened afterward without learning Merkle proofs or attestation mechanics.

## 3. Judge/operator
Needs a transparent timeline showing source tx → attestation → proof → ASC verification → AI decision → Creditcoin execution.

## 4. Developer
Needs deterministic interfaces, local mocks, testnet configuration, logs, and a clear implementation order for Antigravity.
