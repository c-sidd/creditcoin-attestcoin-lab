# 01 — Product Specification

This folder translates the technical architecture into a product that can be demonstrated and judged.

## Required documents

- Product requirements
- Personas and actors
- User stories
- Use cases
- Ideathon pitch

## MVP product promise

A user should be able to initiate a source-chain action and later see, in one place, the evidence that was observed, cryptographically verified, interpreted by the AI layer, checked against deterministic policy, and executed on Creditcoin.

## Judge-facing principle

The strongest demo is not an AI chat window. It is a visible **evidence chain** showing why an automated action was allowed.
