# Transaction History

Display separate source and destination/execution transactions.

Each row contains:
- transaction hash;
- chain/environment;
- block number when known;
- action/event type;
- current lifecycle status;
- timestamp;
- relation to a ProofMind event/decision.

Do not imply that a source transaction and Creditcoin execution are the same transaction. The protocol flow has two transactions: the user transaction on the source chain and the ASC transaction on Creditcoin.
