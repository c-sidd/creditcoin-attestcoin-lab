## Non-Negotiable Requirement

Every submission must meaningfully and functionally integrate the **Attestcoin Protocol**.

A complete submission needs:

- Working Attestcoin integration code running inside the project.
- Technical documentation explaining the setup and how Attestcoin is used.
- Deployment on a testnet.
- Attestcoin as a core feature, not an optional add-on.
- Original work created during the hackathon.

The depth of Attestcoin utilization is a core scoring criterion.

## Available Tracks

1. **DeFi** — lending, trading, liquidity, yield.
2. **RWA** — tokenize, manage, or finance real-world assets.
3. **DePIN** — hardware/sensor coordination and incentives using cross-chain data.
4. **Gaming** — cross-chain economies, ownership, marketplaces.
5. **AI** — AI applications using cryptographically verified cross-chain data to make decisions or trigger transactions without centralized oracle operators.

- Team member information, roles, bios, and required residency/citizenship information

## Strategic Interpretation

The project should be designed around a real cross-chain problem where **verified data from another chain or verified outbound instructions** are essential to the product.

A useful test is:

> What could this project not safely do without Attestcoin?

If the answer is "almost nothing," the integration is probably too shallow.
